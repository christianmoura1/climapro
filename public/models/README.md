# Modelos 3D

Coloque aqui o modelo do ar-condicionado (`.glb`, ou o .zip do glTF baixado
do Sketchfab — a conversão para .glb é feita depois).

Requisitos ao escolher o modelo:
- Licença CC0 (domínio público) ou CC-BY (exige crédito ao autor no rodapé)
- De preferência formato GLB; zip do glTF também serve
- Tamanho até ~20MB (limite de upload do GitHub via navegador é 25MB)
